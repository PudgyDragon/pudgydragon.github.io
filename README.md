# PudgyDragon GitHub Pages

A Jekyll knowledge base for cybersecurity engineering, threat intelligence, blue-team operations, troubleshooting, and STIG guidance.

## Local preview

```bash
bundle install
bundle exec jekyll serve
```

Then open `http://127.0.0.1:4000`.

## Publishing

Push these files to the root of the `PudgyDragon.github.io` repository and enable GitHub Pages from the default branch.
